# XM-Games 界面设计规范

版本：2026-10-23。适用范围：主页及 13 个游戏/工具页面。

本规范是本次审核后建立的维护基准。此前代码使用各页面独立的 Tailwind 配色，没有完整的主题规范或用户可切换的主题系统。下文的四组是页面视觉风格，不是四套可切换皮肤。

## 共用规则

### 页面与响应式布局

- 页面采用深色背景；正文、控件、弹层必须成对指定前景色和背景色。
- 常规页面边距为 16px，紧凑棋盘页可用 8px，并在 `sm`（640px）恢复 16px。内容区域居中，棋盘保持正方形或自身固定比例。
- 标题：手机 18–24px，桌面 24–30px，粗体；控件/正文 14–16px，辅助说明最低 12px。不可用截断隐藏关键标题、语言名称、输入范围。
- 间距使用 4px 基础节奏，通常为 8/12/16/24px；按钮圆角为 `rounded-md`，棋盘为 `rounded-lg`，卡片为 `rounded-xl`。
- 顶栏在窄屏允许分行：返回和语言/操作位于导航行，长标题独占一行。桌面居中标题使用等宽两侧区域，空间不足时仍分行。
- 在 320、360、390、768、1280px 宽度检查。页面本身不得横向溢出；长标签可换行。棋盘不可只压缩网格轨道却保留固定按钮宽度。
- 五子棋等可缩放棋盘须让格线、交点、棋子和点击区域同步缩放。扫雷中/困难棋盘使用局部滚动，完整保留格子尺寸；中国象棋在 320px 等不足以容纳棋盘的宽度下也使用局部滚动。最左、最右和最后一行均须可到达。
- 弹窗保留屏幕边距，最大高度不超过视口的 90%，内容过长时内部滚动；下拉菜单需考虑 Portal 的颜色继承。

### 共用控件与状态

- 共用的语言选择器、默认表单、卡片和默认弹层使用中性的 Slate 深色配色，适用于四组页面。游戏内专用操作与规则弹层可以使用所在组的强调色。
- 共用颜色的唯一默认来源是 `app/globals.css` 的语义变量（`background/foreground`、`card/card-foreground`、`popover/popover-foreground`、`primary/primary-foreground`、`secondary/secondary-foreground`、`accent/accent-foreground` 等）。不要再次引入白色底配浅色文字的默认控件。
- `outline` 按钮明确使用深底、浅字和可见边框；`secondary` 使用 Slate 700 底和浅字；主按钮使用 Slate 600 底和白字。页面覆盖背景时，必须同时检查文字、悬停、焦点、选中和禁用状态。
- 普通按钮默认高 36px，紧凑按钮 32px；主要触屏方向键保持 48×48px。密集棋盘允许更小的目标，但不得重叠，且必须提供准确的位置标签。
- 键盘焦点保留可见描边；禁用控件使用透明度和禁用语义，不能只改颜色。选中状态至少使用填色、边框、图标或文字之一，并保留 ARIA 状态。
- 常规文字目标对比度至少 4.5:1，大字、必要图标及控件边界目标至少 3:1。状态不能仅依赖颜色；低对比的装饰色不能承担阅读任务。
- 图标按钮必须有本地化的可访问名称；表单标签用 `htmlFor/id` 关联；重要范围需始终可见，不能仅写在 placeholder 中。
- 中、英、泰三种语言都需验证；语言选择器完整显示所选语言，不能依赖固定宽度截断。共享顶栏变更必须检查居中型和工具型两种布局。

主页是中性 Slate 导航入口，游戏卡片可预览各组强调色。语言下拉属于共用导航，因此保持 Slate，不随棋盘色改变。

BINGO 的 B/I/N/G/O 依次固定为 Red 500、Orange 500、Yellow 500、Green 500、Blue 500；标题和号码表头保持一致，不附加冲突的 `text-white`。动漫筛选选中项使用更深的状态底色以保证白字可读；未选中项使用 Slate 800 + Slate 100。

## 修改后的验证要求

### 实际操作流程

- 贪吃蛇和俄罗斯方块开始后始终提供重开；暂停必须停止计时推进和方向输入，继续保留当前盘面与分数，重开清空本局状态。回合制棋类、2048 和数独没有持续自动推进，不额外设置暂停按钮。
- 全局游戏快捷键不能接管输入框、语言选择器、菜单、规则弹窗或系统快捷键；空格在聚焦按钮时仍激活该按钮。2048 的 WASD 同时支持大小写。
- 2048 棋盘支持四向滑动，移动距离至少 24px；短触、取消和多指手势不触发走步。棋盘使用 `touch-action: none`，页面其余区域保留滚动。
- 触屏方向按钮至少 48×48px。`pointer: coarse` 设备在平板/横屏宽度也须保留方向按钮和触屏说明，不能只按页面宽度推断有键盘。
- 数独对已正确填写的格子禁用提示，不能无效果扣减提示次数。重开和换难度恢复提示额度。
- Bingo 卡片编号在当前页面会话内递增，删除卡片后不复用已有编号；标记清除保留卡片。
- 追番搜索结果需支持鼠标、触屏及 Tab/Enter 激活；焦点移入结果列表时保持显示。外部搜索超过 10 秒须停止等待并显示重试/手动填写路径，晚到响应不能覆盖新查询。卡片操作及集数按钮提供三语名称，触控目标至少使用共用按钮的 36px 尺寸。

本轮玩法审核覆盖 13 页的真实组件事件与浏览器操作，包括黑白棋完整 60 手、国际象棋王车易位/吃过路兵、中国象棋炮吃子、围棋提子/虚手撤销、扫雷插旗与首点、数独输入/提示、街机暂停/继续/重开、Bingo 自动抽号及卡片管理、追番搜索/编辑/保存。触屏由浏览器粗指针模式及 DOM 手势事件模拟；不视为实体手机、多点触控硬件或真实麦克风验证。

### 连续输入与页面生命周期

- 同一渲染批次收到多次输入时，2048 的方向移动按最新局面依次处理；Bingo 抽号必须保持 1–75 唯一，抽满即停止。开始/暂停切换不能丢失中间操作。
- 棋类棋盘、提子数、回合和历史必须来自同一局面快照；连点落子或悔棋不能重复写入或多删历史。每方一次悔棋的既有规则保持不变。
- 数独同一正确格只能消耗一次提示；追番集数的上下限必须在状态更新中校验，保存按钮的一次表单提交只能产生一条记录。
- 街机重开必须重新计算首次自动推进时间，不能沿用旧局剩余间隔；暂停、重开、离页都清除旧循环，失效回调不得修改新局。俄罗斯方块长按空格的键盘重复事件不连续落下下一块，方向键仍允许长按。
- 路由离页清除游戏计时器、全局按键监听、待重启语音及请求。路由重新挂载游戏时进入初始局面；最高分和已保存的追番记录按既有规则保留。浏览器保留页面实例的 BFCache 返回遵循下节后台恢复规则。
- Bingo 卡片停止识别或清除标记后，不接收旧会话的迟到结果；快速重新开始须等上次识别结束。离页后不得自动重启识别或继续播报。

压力验证包含全部 13 页各 3 次首页/浏览器返回往返（共 39 次），观测活动计时器与键盘监听；同时用逐帧输入和同一任务内批量 DOM 事件验证连点边界。后者是强于普通人工点击的模拟场景，不能表述为实体触屏测试。语音迟到事件和异步停止/重启使用模拟识别器验证，未使用真实麦克风。

### 刷新、后台与多标签页

- 刷新页面开始新局，不恢复未保存的棋盘、抽号、卡片标记或运行中的计时器。最高分、语言选择和明确保存成功的追番记录从本地存储恢复；追番表单草稿不自动保存。
- 页面进入后台由 `visibilitychange` 的隐藏状态或 `pagehide` 判定；普通窗口失焦 `blur` 不等于后台。初始隐藏的页面不得启动自动推进。`pageshow` 和返回可见时检查恢复状态，兼容 BFCache；重复或同批次生命周期事件不能创建重复循环，也不能让旧回调修改当前状态。
- 贪吃蛇和俄罗斯方块进入后台后暂停，保留当前盘面与分数；返回后由用户点击继续，不自动推进。即使开始/继续与隐藏发生在同一批次，也必须以暂停收尾。
- Bingo 进入后台后停止自动抽号并取消播报，保留已抽号码；返回后由用户点击开始恢复当前抽号进程，不自动抽取，也不清空历史。Bingo 卡片进入后台后停止语音识别及待重启任务，忽略迟到结果；返回后保留卡片和标记，由用户重新启动识别。
- 扫雷只累计前台有效游戏时长，后台停止计时，返回保留盘面并继续累计；保留不足一秒的有效时间，不能补计后台时长。重开、结算和离页停止旧计时器。
- 后台暂停属于正常状态，使用所在主题的温和文字及 `role="status"`，Slate 页可用 Slate 300；不使用警告图标、琥珀色错误框或 `role="alert"`。真实的存储、权限及输入错误继续使用错误提示规范。
- 同一浏览器、同源标签页共享最高分、语言和已保存的追番记录。最高分每次在串行锁内读取最新保存值，再保存最大值，较低分不能覆盖其他标签页的纪录；接收外部更新及返回前台时重新读取。明确删除/清空不得被旧缓存或待写任务复活；原本空存储不等于删除，不能因此丢弃首次待写的分数。语言更新同步显示，读取同步事件不反向回写。
- 追番每次修改须在串行锁内基于最新列表应用，集数加减使用增量，不能用旧标签页整表覆盖其他修改。挂载、刷新和收到同步事件时只读取，不回写空列表。编辑中的原记录若已被另一标签页修改或删除，阻止覆盖并保留草稿，明确提示冲突。
- 追番表单只有保存完成后才关闭；等待写入时防止重复提交和更改已提交内容，失败时保留草稿及重试路径。刷新时对未提交草稿、待写入操作及未成功保存的修改给出浏览器离页提示。该提示不等于自动保存：强制关闭、系统终止页面或用户选择放弃未提交内容时，草稿可能丢失。
- 集数等整数输入以及保存数据须通过安全整数校验；拒绝超出 JavaScript 安全整数范围、负数及不符合业务上下限的值。评分等允许小数的字段仍须是有限数且位于规定范围。读取失败或数据非法时提供恢复提示，不覆盖原记录。

### 横竖屏、窗口尺寸与语言切换

- 改变窗口尺寸、横竖屏、缩放或中/英/泰语言时，不得重新开始游戏，也不得清空局面、分数、抽号历史、卡片标记或未保存的表单草稿。运行中的游戏保持原有节拍；仅因输入环境变化而取消尚未完成的手势，不产生额外走步。
- 2048 小屏棋盘的网格轨道、方块与间距共同适配可用宽度，四列始终对齐，不得只缩放方块或让固定宽度挤掉间距。`resize`、`orientationchange`、`visualViewport` 尺寸变化及语言切换都使进行中的触屏手势失效；随后抬手不能使用旧坐标触发移动，新手势仍可正常操作。
- 贪吃蛇和俄罗斯方块在短横屏、粗指针设备上应同时显示可操作棋盘和方向控制区；方向按钮至少 48×48px。通过布局重排或棋盘同比缩放适配空间，不得缩小触控目标，也不得因尺寸变化重置局面、分数或自动推进节拍。
- 规则弹窗左右至少保留 16px 视口边距，保留既有桌面最大宽度。短屏内容在弹窗内部滚动，标题、关闭按钮以及最后一条规则均可到达。尺寸或横竖屏变化时，宽度、高度上限及定位应立即适配新视口，不对这些几何属性做 CSS 过渡，避免过渡中弹窗超出屏幕；打开和关闭的淡入、缩放动画可以保留。
- 追番卡片中的合法长集数和进度可换行，不得将增减按钮挤出卡片或被裁切；按钮保留完整点击区域。表单类型、状态等长标签需完整显示，小屏可改为单列并允许选择框内容换行，不用截断掩盖布局不足。
- Bingo 切换语言不改变已抽号码或当前自动抽号间隔，下一次播报采用新语言；不能因翻译函数或语言依赖变化重建循环、提前或推迟抽号。
- Bingo 卡片名称跟随当前语言显示，卡片编号、号码、标记和胜利状态保持不变。仅切换语言不得再次播报已经处理过的胜利。
- 语音识别切换语言时先安全结束旧会话，再按当前意图启动新语言会话。切换期间的旧结果及旧结束回调不得污染新状态或重复启动；用户停止识别、切到后台和离页优先于语言切换后的自动恢复。
- 布局验证同时检查页面与局部容器的真实边界。页面 `scrollWidth` 正常不代表控件可用：被 `overflow-hidden` 裁切的按钮、侵入相邻列的选择框及无法滚到的弹窗内容也属于问题。对合法长数字、英文长状态和泰语文案分别检查。

### 胜负、结束与异常状态

- 结算保留棋盘/牌面及最终分数，在独立的 `role="status"` 区域写明胜方、和局或游戏结束。完成目标后仍可继续的玩法（2048）与无法继续的终局须区别显示；无路可走时优先显示游戏结束。
- 终局不再显示仍轮到某方、尚可悔棋等进行中提示。棋盘输入、方向键、悔棋、抽取及模式按钮按玩法真正禁用，计时器和自动抽取停止；重新开始/重置保持可操作，并清除上一局结果。
- 胜利与和局使用所在主题的浅色文字；不要把所有胜利统一标红。暖棕组可用 Amber 950 底 + Amber 100 字，Slate 组可用 Amber 200 或 Slate 100。结算数字不得因禁用而淡化。
- 暖棕组胜利/和局使用 Amber 950 底 + Amber 100 字；绿色组使用 Green 950 底 + Yellow 200 字。2048 与扫雷的失败提示使用 Red 950 底 + Red 100 字，避免透明红底叠加页面渐变后对比度不足。18px 粗体仍按普通文字 4.5:1 验收；至少 24px 的普通文字或至少 18.67px 的粗体可采用大字的 3:1 阈值。
- 普通错误使用共用 `InlineNotice`：Amber 950 底、Amber 500 边框、Amber 100 字、警告图标及 `role="alert"`；包含明确原因及恢复方式。输入错误关联输入框或棋盘格，纠正后清除，不使用只有红色的提示。
- 满盘和局、无法落子自动跳过、非法落子、输入超范围/重复、语音权限或网络失败、存储失败、题目生成失败都需有明确反馈。语音失败停止自动重启，保留手动输入；存储读取失败不得用空数据覆盖原记录。
- Bingo 的亮色号码球、已抽号码及已标记卡片使用 Slate 900 字；追番状态徽章使用对应色的 700 阶底 + 白字，与筛选标签保持一致。
- 覆盖中、英、泰三语的成功、失败和恢复路径。罕见终局可在测试中指定初始局面，然后通过真实组件事件进入结算；测试夹具不得成为线上路由或调试入口。

本轮终局审核包含全部 13 页：五子棋黑/白胜及和局，围棋双虚手计分与禁手，国际象棋双方胜及逼和，中国象棋双方胜，黑白棋双方胜/和局/跳过，2048 达标继续与无路可走，扫雷胜负，贪吃蛇撞身与满盘胜利，俄罗斯方块结束，数独完成与错误，Bingo 抽完及卡片胜利，以及追番工具的状态和异常。俄罗斯方块没有独立“通关胜利”分支；围棋使用白棋贴 6.5 目的现有规则，不产生平分和局。
